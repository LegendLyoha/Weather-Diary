# 🌤️ Weather Diary (Дневник погоды)

**Автор:** Алексей Райский

**Версия Python:** 3.8+  
**Тип приложения:** Desktop GUI

## 📋 Описание
Графическое приложение для ведения личного дневника погоды. Позволяет добавлять записи с указанием даты, температуры, описания и наличия осадков. Поддерживает фильтрацию по дате и температуре, а также сохранение/загрузку данных в формате JSON.

## 🚀 Как запустить приложение
1. Убедитесь, что у вас установлен Python 3.8 или выше.
2. Клонируйте репозиторий или скачайте файл `weather_diary.py`.
3. Запустите приложение через терминал:
   ```bash
   python weather_diary.py
